# Nigeria-Disease-Surveillance-and-Dashboard
Disease surveillance project using Power BI for data cleaning, analysis and visualization


Data Cleaning and Preparation Notes

Overview

The disease surveillance dataset was cleaned and prepared for analysis using Microsoft Power BI and Power Query. The purpose of the dashboard is to provide insights into reported disease cases, trends, and patterns to support disease surveillance and data-driven public health decision-making.

Data Cleaning Process

The following data cleaning and preparation steps were carried out:

- Reviewed the dataset structure, fields, and column contents.
- Identified and removed duplicate records where applicable.
- Handled missing, blank, and incomplete values.
- Standardized inconsistent text entries and naming conventions.
- Corrected column data types to ensure accurate analysis.
- Checked the dataset for inconsistencies, errors, and invalid entries.
- Ensured the cleaned data was properly structured for analysis.
- Loaded the cleaned dataset into Power BI for visualization and dashboard development.

Tools Used

- Microsoft Power BI
- Power Query

Dashboard Focus

The Disease Surveillance Dashboard presents a visual overview of disease-related data, highlighting reported cases and patterns across relevant categories. It is designed to make the data easier to understand by presenting key indicators, trends, and comparisons in an interactive format.

Outcome

The dataset was successfully cleaned, validated, and prepared for analysis. The resulting data was used to develop an interactive Disease Surveillance Dashboard that provides a clear visual representation of disease patterns and supports data-driven public health analysis.
